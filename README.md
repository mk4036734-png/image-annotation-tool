# AI Image Annotation Tool

## Project Description

The AI Image Annotation Tool is a web-based application developed using Flask, HTML, CSS, and JavaScript. It allows users to upload an image, draw bounding boxes around objects, assign labels, and save the annotations in JSON format. These annotations can be used for training computer vision and artificial intelligence models.

## Features

- Upload Image
- Draw Bounding Box
- Add Object Label
- Save Annotation as JSON
- Simple and User-Friendly Interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## Installation

1. Install Python
2. Install Flask

```
pip install flask
```

3. Run the project

```
python app.py
```

4. Open

```
http://127.0.0.1:5000
```
